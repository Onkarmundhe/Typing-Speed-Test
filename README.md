# Typing Speed Test

A modern, responsive typing speed test application that measures your typing speed (WPM), accuracy, and streak. Built with JavaScript, HTML, and CSS.

## Features

- **Real-time Speed Tracking**: Measures words per minute (WPM) in real-time
- **Accuracy Monitoring**: Tracks typing accuracy percentage
- **Streak Counter**: Shows current streak of correctly typed words
- **Adaptive Cursor**: Visual cursor that follows your typing position
- **Theme Support**: Light and dark theme options
- **60-Second Tests**: Standard one-minute typing tests
- **Error Tracking**: Immediate visual feedback for typing mistakes

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/Onkarmundhe/typing-speed-test.git
```

2. Run this command on terminal python -m http.server 8000 

## How to Use

1. Click on the typing area to start
2. Type the words as they appear
3. Space bar to move to next word
4. Backspace to correct mistakes
5. Test automatically ends after 60 seconds
6. Click "New Game" to restart

## Controls

- `Space` - Next word
- `Backspace` - Delete previous character
- `Click "New Game"` - Start a new test
- `Click "Toggle Theme"` - Switch between light and dark themes

## Technical Details

- Built with JavaScript (no frameworks)
- Uses CSS Grid and Flexbox for layout
- Implements custom cursor animation
- Font: Roboto & Roboto Mono from Google Fonts
